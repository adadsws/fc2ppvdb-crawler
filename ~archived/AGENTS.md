# AGENTS.md

## 项目专用规则

- 将整个项目当前内容视为最新且正确的状态。
- 不要回退、覆盖或丢弃用户/其他进程的修改；无关修改保持原样。
- 如果提交时混有无关用户修改，要与 Codex 修改分开提交。
- `AGENTS.md` 是本地规则文件，保持忽略状态，不要提交或推送。

## 文档更新规则

- 每次变更后检查是否需要更新文档。
- 功能、修复、结构、配置、工具或跟踪策略变化时更新 `CHANGELOG.md`。
- 使用方法、命令、参数、项目结构或依赖变化时更新 `README.md`、`requirements.txt`、`.gitignore` 或 `run_*.bat`。
